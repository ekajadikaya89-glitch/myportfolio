## Summary of Fixes Applied (`#1` to `#10`)

### HIGH (Hard Gate)
1. **[R-32] Modal focus traps & visible search focus:** Added `Tab`/`Shift+Tab` keyboard focus trapping to both `CommandPalette` (`components/navigation/command-palette.tsx`) and `ScreenshotGallery` lightbox (`components/projects/screenshot-gallery.tsx`), and removed `focus:outline-none` on the `CommandPalette` search input so the global `:focus-visible` ring remains clearly visible.
2. **[R-39] ARIA semantics, error binding & `:active` affordances:** Upgraded `CommandPalette` to the WAI-ARIA `combobox` + `aria-controls` + `aria-activedescendant` + `listbox`/`group`/`option` pattern; bound `#assistant-query` to `#assistant-error` (`role="alert"`) via `aria-invalid` and `aria-describedby` in `components/sections/portfolio-assistant.tsx`; and added `active:translate-y-px` states to lightbox buttons, assistant citations/trace toggle, article prev/next navigation cards, and About social links.
3. **[R-03] Mobile tap targets & 375px timeline clearance:** Raised article TOC links in `app/[locale]/insights/[slug]/page.tsx` to `min-h-11` (`>= 44px`), and added `ml-4 md:ml-5` to the Experience timeline list in `app/[locale]/experience/page.tsx` so timeline icon badges stay comfortably inside the 375px viewport margin.
4. **[R-27] Assistant loading state & CommandPalette empty reset:** Added an explicit `role="status"` loading state (`loadingState`) and `aria-busy` in `components/sections/portfolio-assistant.tsx`, and added a one-click `"Clear search"` / `"Hapus pencarian"` reset button in `CommandPalette`'s empty state (`i18n/dictionaries/en.ts`, `i18n/dictionaries/id.ts`).
5. **[R-40] Intrinsic image dimensions & immediate first paint:** Added `width={1440} height={900}` to both thumbnail and lightbox `<img>` elements in `components/projects/screenshot-gallery.tsx`, and removed `opacity: 0` from `app/[locale]/template.tsx` so initial SSR content paints immediately without waiting for hydration.
6. **[R-34] Dark-mode print parity on `/resume`:** Extended `@media print` in `app/globals.css` to normalize `:root` and `.dark` CSS tokens to crisp white paper (`#ffffff`) and dark ink (`#0b0c0e`) so printing `/resume` from Dark Mode produces a clean document.

### MEDIUM (Purpose-Gate)
7. **[R-10] Glassmorphism dose cap restored:** Removed `backdrop-blur-sm` from `CommandPalette` and `ScreenshotGallery` backdrops, keeping `backdrop-blur-md` strictly on 1 element (`SiteHeader` when scrolled), matching `DESIGN.md`.
8. **[R-08] Decorative arrows removed from `ProofStrip`:** Removed `ArrowRightIcon` from all 4 internal cards in `components/sections/proof-strip.tsx`, using clean hover underline + border elevation instead.

### LOW (Quality Locks & UX Polish)
9. **[R-24, C-4] Desktop Resume access & CommandPalette coordination:** Changed the desktop Resume link in `components/navigation/site-header.tsx` from `2xl:inline-flex` to `lg:inline-flex` so 1024px–1440px laptop screens see Resume directly in the header; persisted `LOCALE_COOKIE` when switching language via `CommandPalette`; and wired `onBeforeOpen={() => setOpen(false)}` so opening `CommandPalette` closes an open mobile nav drawer cleanly.
10. **[R-26, C-2] Clickable web resume links & localized role subtitle:** Converted LinkedIn, GitHub, and Email entries on `app/[locale]/resume/page.tsx` into real `<a href>` links, and replaced hardcoded English `"AI Engineer & Full-Stack Developer"` in `app/[locale]/about/page.tsx` and `app/[locale]/resume/page.tsx` with `dict.about.roleTitle`.
